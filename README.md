# RFCs

RFCs for the Sic programming language.
An RFC (request for comments) proposes a substantial change to the language, its tools or the project, and records the decision with its rationale.
They are published as a book, [The Sic RFC Book](https://sic-lang.github.io/rfcs/).
[`CONTRIBUTING.md`](https://github.com/sic-lang/rfcs/blob/main/CONTRIBUTING.md) describes how to create and change an RFC.
